# Troubleshooting

## The application keeps crashing or freezing

First, check the status page for any ongoing incident — most sudden,
widespread crashes are on our end, not yours. If the status page is
clear: clear your browser cache, make sure your browser is updated to
the latest version, and try disabling browser extensions one at a time,
since ad blockers and privacy extensions are the most common cause of
this symptom.

## Attachments fail to upload

Attachments must be under 25MB and in a supported format (PDF, PNG, JPG,
CSV, DOCX). Uploads that fail partway through are usually a network
issue rather than a file problem — try a different network or disable
any VPN. If a specific file consistently fails under the size limit,
contact support with the file type and size so it can be investigated.

## Shared inbox isn't syncing new emails

First check Settings > Integrations to confirm the email connection
still shows "Connected" — integrations occasionally need to be
reauthorized after the email provider revokes access (common after a
password change on the connected mailbox). New emails can also take up
to 15 minutes to appear during normal sync delay, which is expected
behavior, not a fault.

## Automation rules aren't triggering

Automation rules are only available on Pro and Business plans — confirm
your plan under Settings > Billing. If you're on an eligible plan, check
that the rule's trigger conditions match the incoming email exactly;
the most common cause is a trigger condition that's more specific than
intended (for example, matching an exact subject line instead of a
keyword).

## General steps before contacting support

Note the exact error message if one appears, the browser and OS you're
using, and roughly when the issue started. Including these details in
your first message to support significantly speeds up resolution.
